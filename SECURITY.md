# Security status

This is a verified development candidate, not an approved production service. Live payments and report issuance remain gated by configuration and release evidence. See docs/READINESS.md.

Do not place credentials, customer records, photographs, signed reports or database exports in public issues, logs or commits. Establish a private security-reporting contact and response procedure before customer onboarding. A passing CI run is not a penetration test, legal certification or deployment authority.
